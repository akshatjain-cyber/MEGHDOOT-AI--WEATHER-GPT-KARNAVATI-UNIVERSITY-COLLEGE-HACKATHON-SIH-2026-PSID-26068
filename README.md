## Project Overview

**Meghdoot AI** is an intelligent, real-time weather intelligence and disaster response system designed to streamline emergency rescue operations during severe meteorological events. Built on modern web technologies and full-stack TypeScript, the platform combines conversational weather intelligence (Weather GPT), dynamic geofencing, real-time alert systems, and rescue command management into a unified dashboard.

---

## Key Features

* **Weather GPT Assistant:** Interactive conversational agent providing meteorological insights, severity analyses, and actionable disaster protocols.
* **Interactive Rescue Command Map:** Geospatial tracking interface with customizable radius geofencing for distress monitoring and resource allocation.
* **Voice & Multilingual Accessibility:** Speech synthesis/voice command capabilities alongside localized emergency guidance.
* **Incident Management Dashboard:** Real-time updates on active relief efforts, safe evacuation routes, and field resource status.
* **Reliable Fallback Architecture:** Resilient backend designed with schema-backed persistence and failover routines for low-connectivity environments.

---

## Tech Stack

* **Frontend:** React 18, Vite, TypeScript, Tailwind CSS, Radix UI (shadcn/ui), Wouter Routing
* **Backend:** Node.js, Express, tRPC (end-to-end typesafe APIs)
* **Database & ORM:** PostgreSQL / SQLite with Drizzle ORM
* **Testing:** Vitest
